# Tarot

Hello World estático publicado no GitHub Pages.

## Site

- Fonte publicada: [`docs/`](docs/) na branch `main`
- URL do projeto: https://masterxio.github.io/tarot/

## Publicação

O site segue o fluxo oficial de GitHub Pages para conteúdo estático sem build:

- origem: branch `main`, pasta `/docs`
- [`.nojekyll`](docs/.nojekyll) para publicar HTML puro, sem o processador Jekyll
- [`404.html`](docs/404.html) como página de erro personalizada

Para pré-visualizar localmente, abra `docs/index.html` no navegador.
